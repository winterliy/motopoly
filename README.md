# Motopoly

WorldEdit처럼 구역을 고르면, 그 자리에 **주변 지형과 자연스럽게 이어지는 새 땅**을 만들어 주는 Paper 플러그인이에요. 건축 부지를 만들 때 써요.

- 구역 안에 원래 있던 것(건물, 나무, 물, 구덩이)은 무시하고, **바깥 테두리 지형**만 보고 새 지표면을 설계해요.
- 새 지표면 위의 블록은 전부 지우고, 아래 빈 공간(공기, 물)은 땅으로 채워요.
- 대상: Paper 26.3 (Java 25)
- 언어: 지형 알고리즘은 Java(`src/main/java`), 플러그인 연결부는 Kotlin(`src/main/kotlin`)

## 설치

```bash
./gradlew build
```

`build/libs/motopoly-<버전>.jar`를 서버의 `plugins/` 폴더에 넣으면 돼요. Kotlin 런타임은 jar에 넣지 않았어요. 서버가 처음 켜질 때 `plugin.yml`의 `libraries` 항목을 보고 Maven Central에서 내려받아요.

## 사용법

| 명령어 | 설명 |
|---|---|
| `/mt help` | 명령어 목록과 옵션을 보여 줘요 |
| `/mt wand` | 선택 도구(황금 삽)를 받아요. 좌클릭은 1번 지점, 우클릭은 2번 지점이에요 |
| `/mt pos1`, `/mt pos2` | 지금 서 있는 위치를 지점으로 찍어요 |
| `/mt info` | 구역 주변 지형을 분석하고 추천 옵션을 보여 줘요 |
| `/mt gen [옵션…]` | 땅을 생성해요 (`/mt generate`도 돼요) |
| `/mt edge [n\|reset]` | 가장자리 스무딩 폭(블록)을 확인하거나 바꿔요. 기본 10블록이고, 플레이어마다 저장돼서 서버를 재시작해도 유지돼요 |
| `/mt undo` | 마지막 작업을 되돌려요 (기본 5단계) |
| `/mt reload` | `config.yml`을 다시 불러와요 |

권한은 `motopoly.use`(기본값: OP)예요. 선택 영역은 XZ 평면 기준이라 Y값은 무시해요. 선택 도구는 황금 삽이라 WorldEdit의 나무 도끼와 겹치지 않아요.

### gen 옵션

| 옵션 | 기본값 | 의미 |
|---|---|---|
| `height=<y\|auto>` | `auto` | 구역 안쪽 목표 높이예요. `auto`면 주변 지형만 따라가요. 숫자를 주면 테두리에서 `edge`칸에 걸쳐 그 높이로 서서히 바뀌어요 |
| `rough=<n\|auto>` | `auto` | 기복의 최대 높이(블록)예요. `auto`면 주변 지형 거칠기에 맞춰 0.4~2 사이로 정해요. `0`이면 기복이 없어요 |
| `scale=<n>` | `48` | 기복의 가로 크기예요. 클수록 더 완만한 언덕이 돼요 |
| `edge=<n>` | `/mt edge` 값 | 이번 실행에만 쓸 가장자리 스무딩 폭이에요 |
| `smooth=<n>` | `2` | 마무리 스무딩을 몇 번 할지예요 |
| `seed=<n>` | 월드 시드 | 노이즈 시드예요. 같은 시드면 이웃한 구역끼리도 기복이 이어져요 |

예시:

```
/mt gen                      # 주변 지형에 맞춘 자연스러운 땅
/mt gen height=70 rough=0    # 안쪽은 Y=70 평면, 테두리는 주변과 이어지는 경사
/mt gen rough=2 scale=80     # 넓고 완만한 굴곡이 있는 땅
```

## 알고리즘

### 바닐라 지형 분석

1.18 이후의 바닐라 지형은 3D 밀도 함수로 만들어져요. 지형의 큰 모양을 정하는 노이즈는 네 가지예요.

- **continentalness**: 바다와 내륙을 나눠요
- **erosion**: 침식 정도예요. 값이 높을수록 지형이 낮고 평평해져요
- **peaks & valleys (weirdness)**: 봉우리와 골짜기를 만들어요
- **jaggedness**: 산의 뾰족함을 더해요

**평원은 erosion이 높은 경우**예요. 큰 높낮이가 거의 사라지고, 진폭이 작은 옥타브 Perlin 노이즈만 남아요.

### Motopoly가 하는 일 (`TerrainGenerator`)

1. **주변 읽기**: 구역과 사방 8블록 여백의 청크 스냅샷에서 칸마다 지표면을 찾아요. 나무, 잎, 풀은 건너뛰고, 물은 수면 높이로 봐요. 그래서 호숫가에서는 새 땅이 물가처럼 수면에 맞닿아요.
2. **막 곡면 (라플라스 보간)**: 구역 바로 바깥 한 줄의 높이를 고정하고, 안쪽은 라플라스 방정식을 풀어 채워요. 이렇게 만든 곡면은 모든 테두리에 딱 맞는 가장 매끄러운 곡면이에요. 한쪽이 높고 반대쪽이 낮으면 그 사이를 자연스러운 경사로 이어요. 계산은 SOR(과완화 반복법)로 해요.
3. **목표 높이** (`height=`): 숫자를 주면 테두리에서 `edge`칸에 걸쳐 S자 곡선(smoothstep)으로 그 높이까지 서서히 바꿔요.
4. **자연스러운 기복**: 바닐라 `ImprovedNoise`와 같은 구조의 4옥타브 Perlin 노이즈를 더해요. 여기에 더 느린 "erosion" 노이즈를 곱해서 기복 세기가 지역마다 35~100% 사이로 달라지게 해요. 기복도 `edge`칸에 걸쳐 서서히 커져서, 경계에서는 높이가 주변과 딱 맞아요.
5. **스무딩**: 1-2-1 커널로 블러한 뒤 정수 높이로 반올림해요.
6. **블록 배치** (`GenerateJob`):
   - 새 지표면 위는 꼭대기까지 전부 공기로 바꿔요. 건물, 나무, 횃불, 물이 모두 지워져요.
   - 지표면에는 **가장 가까운 바깥 테두리 칸의 재질 층**을 그대로 깔아요. 예를 들어 잔디 → 흙 3칸 → 돌이에요.
   - 그 아래 공기나 물은 단단한 땅이 나올 때까지 채워요. 최대 `max-fill-depth`(기본 64)블록이에요.

`/mt info`의 거칠기는 4-이웃 라플라시안의 절댓값 평균이에요. 바닐라 평원은 대략 0.2~0.8, 구릉은 1~2, 산악은 2를 넘어요.

### 성능

- 청크는 비동기로 로드하고, 지형 분석과 변경 목록 계산은 비동기 스레드에서 해요.
- 블록 쓰기는 메인 스레드에서 틱당 `blocks-per-tick`개씩 나눠서, 물리 연산 없이 해요.
- 되돌리기 기록은 블록 위치를 long 하나에 압축하고 블록 상태는 팔레트로 저장해요. 수백만 블록을 바꿔도 메모리를 적게 써요.

## 알아둘 점

- 구역 안의 건물도 지표면 위에 있으면 모두 지워져요. 실수했다면 `/mt undo`로 되돌리세요.
- 구역 바로 바깥에 건물이 붙어 있으면, 그 건물 높이를 지형으로 보고 이어질 수 있어요. 구역을 건물에서 조금 떨어뜨려 잡으세요.
- 물리 연산을 끄고 써서, 구역 경계에 걸친 물은 바로 흘러들지 않고 물 벽처럼 남을 수 있어요.
- 작업 중에 다른 사람이 그 구역을 고치면, 그 변경은 덮어써질 수 있어요.

./gradlew test
