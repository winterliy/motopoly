# Motopoly

WorldEdit처럼 구역을 고르면 **구역 전체를 새 땅으로 채우고, 구역 바깥의 연결 지대로 주변 지형과 자연스럽게 이어 주는** Paper 플러그인이에요. 건축 부지를 만들 때 써요.

- 선택 구역이 곧 생성 구역이에요. 두 지점의 Y가 같으면 구역 전체가 그 높이의 평지가 되고, 다르면 두 Y 사이에서 높낮이가 있는 땅이 돼요.
- 구역 바깥 `distance`칸(기본 10)이 연결 지대예요. 이 띠의 땅을 깎거나 쌓아서 새 땅과 원래 지형을 이어요. 높이 차가 크면 경사가 가팔라져요(한 칸에 여러 블록).
- 구역 안에 원래 있던 것(건물, 나무, 물, 구덩이)은 무시하고 새 지표면을 설계해요.
- 새 지표면 위의 블록은 전부 지우고, 아래 빈 공간(공기, 물)은 땅으로 채워요.
- 대상: Paper 26.3 (Java 25)
- 언어: 지형 알고리즘은 Java(`src/main/java`), 플러그인 연결부는 Kotlin(`src/main/kotlin`)

## 설치

```bash
./gradlew build
```

`build/libs/motopoly-<버전>.jar`를 서버의 `plugins/` 폴더에 넣으면 돼요. Kotlin 런타임은 jar에 넣지 않았어요. 서버가 처음 켜질 때 `plugin.yml`의 `libraries` 항목을 보고 Maven Central에서 내려받아요.

## 사용법

1. **구역 지정**: `/mt pos1`, `/mt pos2`로 지금 서 있는 위치를 두 꼭짓점으로 찍어요. `/mt wand`로 받은 황금 삽으로 좌클릭/우클릭해도 돼요.
2. **땅 생성**: `/mt gen`을 치면 **두 지점의 Y**로 구역 전체를 새 땅으로 만들어요. 두 Y가 같으면 그 높이의 평지를, 다르면 낮은 Y~높은 Y 사이에서만 높낮이가 있는 땅을 만들어요. 예: pos1 `(0, 64, 0)`, pos2 `(10, 61, 10)` → Y 61~64 사이에서 굴곡. 구역 바깥 `distance`칸은 주변 지형과 이어지도록 깎거나 쌓아요. 지표면 블록은 주변을 분석해서 같은 재질로 깔아요.
   - `/mt gen <y>`처럼 Y를 직접 주면 두 지점의 Y 대신 그 높이의 평지를 만들어요.
   - 지점의 Y는 WorldEdit처럼 찍힌 그대로예요. `/mt pos1`은 발 위치(밟은 블록 한 칸 위)를, 선택 도구는 클릭한 블록을 저장해요. 그래서 땅 위에 서서 `/mt pos1`로 찍으면 지표면이 서 있던 땅보다 1칸 높게 생겨요.
3. **설정 변경**: `/mt config <distance|round|rough|step> [값]`으로 바꿔요. 값을 빼면 기본값으로 돌아가요.
4. **되돌리기**: `/mt undo`로 마지막 작업을 되돌려요 (기본 5단계).

| 명령어 | 설명 |
|---|---|
| `/mt pos1`, `/mt pos2` | 구역 꼭짓점 지정 |
| `/mt wand` | 선택 도구(황금 삽) 받기. 좌클릭 1번, 우클릭 2번 지점 |
| `/mt gen` | 두 지점의 Y 범위로 생성. 같으면 평지, 다르면 그 범위 안에서 높낮이 (`/mt generate`도 돼요) |
| `/mt gen <y>` | 구역 전체를 Y 높이의 평지로 생성 |
| `/mt config` | 현재 설정 보기 |
| `/mt config distance [0~64]` | 구역 바깥 연결 지대 폭(블록). 기본 10, 0이면 구역 밖은 건드리지 않아요 |
| `/mt config round [0~100]` | 구역 모서리를 둥글게 깎는 정도. 기본 0(네모), 100이면 모서리 반지름이 짧은 변의 절반(정사각형이면 원) |
| `/mt config rough [auto\|0~16]` | 두 지점의 Y가 다를 때 얹는 잔 굴곡(블록). 기본 auto, 0이면 잔 굴곡 없음 |
| `/mt config step [0~16]` | 연결 지대에서 옆 칸끼리 목표 최대 높이 차(블록). 기본 1, 0이면 제한 없음. 지대가 높이 차에 비해 좁으면 이보다 가팔라져요 |
| `/mt undo` | 마지막 작업 되돌리기 |
| `/mt info` | 구역과 주변 지형 분석, 추천 높이 |
| `/mt help` | 사용 순서 보기 |
| `/mt reload` | `config.yml` 다시 불러오기 |

- 권한은 `motopoly.use`(기본값: OP)예요.
- `distance`, `round`, `rough`, `step`은 플레이어마다 저장돼서 서버를 재시작해도 유지돼요. 서버 기본값은 `config.yml`의 `defaults`에서 바꿔요.
- 선택 도구는 황금 삽이라 WorldEdit의 나무 도끼와 겹치지 않아요.

예시:

```
/mt pos1
/mt pos2
/mt gen                    # 두 지점의 Y 범위 안에서 생성 (같으면 평지)
/mt gen 70                 # 구역 전체를 Y=70 평지로, 바깥 10블록은 주변과 이어지는 경사
/mt config distance 20     # 구역 밖 20블록에 걸쳐 더 길고 완만하게 이음
/mt config distance 3      # 구역 밖 3블록만 사용 (높이 차가 크면 한 칸에 여러 블록씩)
/mt config round 50        # 구역 모서리를 둥글게 (100이면 원·타원에 가까움)
/mt config rough 0         # 높이 범위에서 잔 굴곡 없이
/mt config rough           # 기본값(auto)으로 되돌리기
```

## 알고리즘

### 바닐라 지형 분석

1.18 이후의 바닐라 지형은 3D 밀도 함수로 만들어져요. 지형의 큰 모양을 정하는 노이즈는 네 가지예요.

- **continentalness**: 바다와 내륙을 나눠요
- **erosion**: 침식 정도예요. 값이 높을수록 지형이 낮고 평평해져요
- **peaks & valleys (weirdness)**: 봉우리와 골짜기를 만들어요
- **jaggedness**: 산의 뾰족함을 더해요

**평원은 erosion이 높은 경우**예요. 큰 높낮이가 거의 사라지고, 진폭이 작은 옥타브 Perlin 노이즈만 남아요.

### Motopoly가 하는 일 (`TerrainGenerator`)

1. **주변 읽기**: 구역과 사방 `distance` + 8블록 여백의 청크 스냅샷에서 칸마다 지표면을 찾아요. 나무, 잎, 풀은 건너뛰고, 얼음은 수면으로 봐요. 물속은 바닥을 찾되, 물 밑으로 뚫린 동굴로는 내려가지 않아요.
   - **튀는 값 제거**: 테두리 높이에 5×5 중앙값 필터를 걸어서, 2칸 폭 이하의 협곡·동굴 입구·기둥 때문에 새 땅이 끌려가지 않게 해요.
   - **물속도 땅처럼**: 바다·강·호수에서는 물 밑 진짜 바닥 높이를 지형으로 봐요. 연결 지대는 땅에서와 똑같이 S자 경사로 원래 바닥까지 내려가서, 물속에서 지형이 끊어지거나 절벽이 생기지 않아요.
2. **생성 구역** (선택 구역 전체):
   - **한 층** (두 지점의 Y가 같거나 `/mt gen <y>`): 구역 전체가 그 높이의 완전 평면이에요.
   - **여러 층** (두 지점의 Y가 다름): 높이가 낮은 Y~높은 Y 사이에서 굽이쳐요. 모양은 바닐라 지형의 큰 굴곡(로우패스)을 구역 안에서 범위에 맞게 늘려서 쓰고, 그게 거의 평평하면 느린 Perlin 노이즈를 써요. 그 위에 잔 굴곡(`rough`)을 얹고 1-2-1 블러를 두 번 한 뒤, 범위를 벗어나지 않게 자르고 옆 칸끼리 `step`보다 차이 나지 않게 깎아요.
3. **잔 굴곡 (바닐라 지형)**: 월드 자신의 바닐라 생성기(`getBaseHeight`)에 그 좌표의 지형 높이를 물어봐요. 청크를 만들거나 불러오지 않고 노이즈만 계산하는 거라, 참조 월드도 필요 없고 처음에 멈칫하지도 않아요(비동기, 여러 스레드). 이 높이에서 흐리게 만든 복사본을 빼서(하이패스 필터) 산·골짜기 같은 큰 모양은 버리고, `scale/4`블록보다 작은 **진짜 바닐라의 잔 굴곡**만 남겨요.
   - 바닐라 생성기를 못 쓰거나(`vanilla-terrain: false`, 바닐라가 아닌 생성기) 그 자리가 완전히 평평하면, 바닐라 평원을 흉내 낸 4옥타브 Perlin 노이즈로 대신해요.
4. **연결 지대** (구역 바깥 `distance`칸): 칸마다 구역에서 가장 가까운 칸의 높이에서 원래 지형 높이까지, 구역에서 떨어진 거리에 따라 S자 곡선(smoothstep)으로 서서히 바꿔요. 곡선의 양 끝이 평평해서 구역 쪽에도, 주변 지형 쪽에도 꺾인 자국이 남지 않아요. 원래 지형의 잔 굴곡은 바깥으로 갈수록 그대로 살아나요.
   - **둥근 모서리** (`round`): 구역을 모서리가 둥근 사각형으로 봐요. 반지름은 `round`/100 × 짧은 변의 절반이에요. 깎여 나간 구역 모서리 칸은 연결 지대가 돼서, 둥근 테두리에서부터 거리에 따라 원래 지형으로 이어져요. 연결 지대 바깥 테두리도 같이 둥글어져요. 테두리에서 `distance`칸보다 먼 모서리 칸은 원래 지형(건물·나무 포함)을 그대로 둬요.
   - 띠 바깥은 전혀 바꾸지 않아요. 연결 지대에서도 높이가 그대로인 칸은 건드리지 않아요.
5. **경사 다듬기 (열 침식)**: 연결 지대에서 이웃한 칸끼리 `step`보다 크게 차이 나지 않게 해요. 열 침식(안식각) 시뮬레이션이 결국 도달하는 상태를 거리 변환으로 바로 계산해요.
   - 생성 구역은 고정이에요. 높이 차가 `distance`칸 안에 `step`으로 오를 수 있는 것보다 크면, 구역을 바꾸는 대신 경사를 그만큼 가파르게 해요(한 칸에 5블록, 10블록씩도 돼요). 완만하게 하고 싶으면 `/mt config distance`를 늘리세요.
6. 정수 높이로 반올림해요.
7. **블록 배치** (`GenerateJob`): 칸마다 재질을 정해요.
   - 새 지표면 위는 꼭대기까지 전부 비워요. 건물, 나무, 횃불이 모두 지워져요. 단, **수면보다 낮은 칸은 수면까지 물로 채워서** 바다나 호수에 구멍이 생기지 않아요.
   - **물속** (수면보다 낮은 칸 전부): 주변의 **진짜 바다·강·호수 바닥**(물 아래가 땅인 칸) 중 가장 가까운 칸의 재질 층(모래, 자갈, 점토, 흙 등)을 써요. 찾는 위치를 느린 노이즈로 몇 칸씩 흔들어서, 재질이 테두리 쪽 줄무늬가 아니라 바닐라처럼 얼룩덜룩한 무리로 섞여요. 물에 잠긴 잔디·흙길은 흙으로 바꿔요. 근처에 쓸 바닥이 없으면 모래 → 자갈이에요.
   - **연결 지대의 땅**: 그 칸에 원래 있던 재질 층과 풀을 그대로 옮겨요.
   - **해변** (수면 ~ +2, 물에서 `beach-width`칸 이내): 근처 물 바닥이 모래일 때만 모래 4칸 위에 사암(붉은 모래면 붉은 사암)이에요. 바닥이 자갈·흙·점토인 강이나 호수 가에는 모래를 깔지 않고 보통 땅으로 이어요.
   - **땅**: 바닐라가 그 자리에 만들 **바이옴**의 지표 재질을 써요. 예: 평원·숲은 잔디 → 흙 3칸 → 돌, 사막은 모래 → 사암, 악지는 붉은 모래 → 테라코타, 버섯 들판은 균사체, 거대 타이가는 포드졸, 눈 덮인 산봉우리는 눈 블록, 맹그로브 늪은 진흙, 눈 바이옴은 눈 덮인 잔디예요. 바닐라에서 그 자리가 물이면 가장 가까운 바깥의 마른 땅 재질을, 그것도 없으면(바다 위 섬) 잔디 → 흙 → 돌을 써요.
   - **식생**: 새 잔디에는 바닐라 평원 정도의 밀도로 풀과 꽃을 심고, 눈 바이옴에는 눈을 한 겹 덮어요(`copy-plants`). 연결 지대는 원래 있던 풀을 그대로 옮겨요. 나무는 심지 않아요.
   - 그 아래 공기, 물, 그리고 새 땅에 묻힐 나무·잎은 진짜 땅이 나올 때까지 채워요. 최대 `max-fill-depth`(기본 64)블록이에요.
   - **광석**: 새로 채운 돌·심층암에는 바닐라처럼 높이에 따라 광석 덩어리가 섞여요(`fill-ores`). 석탄은 높은 곳, 철은 두 높이대, 구리는 Y 48 근처, 금·레드스톤·청금석은 깊은 곳, 다이아몬드는 Y 16 아래에서만 나와요. 2×2×2 칸 단위로 광맥을 정해서 낱개가 아닌 덩어리로 나오고, 위치와 시드로만 정해져서 같은 자리는 항상 같아요(`OreTable`).
   - **묻힌 지표**: 땅을 올리면 원래 지표의 잔디·포드졸·균사체·흙길·경작지가 새 땅 밑에 묻혀요. 이 칸은 흙으로 바꿔요.

`/mt info`의 거칠기는 4-이웃 라플라시안의 절댓값 평균이에요. 바닐라 평원은 대략 0.2~0.8, 구릉은 1~2, 산악은 2를 넘어요.

### 성능

- 청크는 비동기로 로드하고, 지형 분석과 변경 목록 계산은 비동기 스레드에서 해요.
- 블록 쓰기는 메인 스레드에서 틱당 `blocks-per-tick`개씩 나눠서, 물리 연산 없이 해요.
- 되돌리기 기록은 블록 위치를 long 하나에 압축하고 블록 상태는 팔레트로 저장해요. 수백만 블록을 바꿔도 메모리를 적게 써요.

## 알아둘 점

- 1.3~2.3에서 쓰던 참조 월드 폴더(`motopoly_ref_world` 등)는 더 이상 쓰지 않아요. 서버 폴더에서 지워도 돼요.

- 구역 안의 건물도 지표면 위에 있으면 모두 지워져요. 실수했다면 `/mt undo`로 되돌리세요.
- **구역 바깥 `distance`칸도 바뀌어요.** 연결 지대에서 높이가 바뀌는 칸은 그 위의 건물·나무가 지워지고, 칸 밖으로 뻗은 나뭇잎이 떠 있을 수 있어요. 건드리면 안 되는 게 가까이 있으면 distance를 줄이세요(0이면 구역 밖은 그대로예요).
- 연결 지대 안의 건물은 지형으로 보고 이어질 수 있어요.
- 물리 연산을 끄고 써서, 구역 경계에 걸친 물은 바로 흘러들지 않고 물 벽처럼 남을 수 있어요.
- 깊은 물 옆에서는 연결 지대가 깊은 바닥까지 내려가야 해서 물속 경사가 가팔라질 수 있어요. 완만하게 하려면 distance를 늘리세요.
- 1.x에서 `/mt config smooth`로 저장한 값은 distance로 그대로 쓰여요.
- 작업 중에 다른 사람이 그 구역을 고치면, 그 변경은 덮어써질 수 있어요.
