# Motopoly

WorldEdit처럼 영역을 골라서, 그 안의 지형을 **바닐라 평원처럼 자연스러운 평지**로 다듬는 Paper 플러그인이에요. 건축 부지를 만들 때 써요.

- 대상: Paper 26.3 (Java 25)
- 언어: 지형 알고리즘은 Java(`src/main/java`), 플러그인 연결부는 Kotlin(`src/main/kotlin`)

## 설치

```bash
./gradlew build
```

`build/libs/motopoly-1.0.0.jar`를 서버의 `plugins/` 폴더에 넣으면 돼요. Kotlin 런타임은 jar에 넣지 않았어요. 서버가 처음 켜질 때 `plugin.yml`의 `libraries` 항목을 보고 Maven Central에서 내려받아요.

## 사용법

| 명령어 | 설명 |
|---|---|
| `/mt help` | 명령어 목록과 옵션을 보여 줘요 |
| `/mt wand` | 선택 도구(황금 삽)를 받아요. 좌클릭은 1번 지점, 우클릭은 2번 지점이에요 |
| `/mt pos1`, `/mt pos2` | 지금 서 있는 위치를 지점으로 찍어요 |
| `/mt info` | 선택 영역의 지형을 분석해요. 높이, 거칠기, 지형 종류, 추천 옵션을 보여 줘요 |
| `/mt flatten [옵션…]` | 평탄화를 실행해요 |
| `/mt edge [n\|reset]` | 가장자리 스무딩 폭(블록)을 확인하거나 바꿔요. 기본 10블록이고, 플레이어마다 저장돼서 서버를 재시작해도 유지돼요 |
| `/mt undo` | 마지막 작업을 되돌려요 (기본 5단계) |
| `/mt reload` | `config.yml`을 다시 불러와요 |

권한은 `motopoly.use`(기본값: OP)예요. 선택 영역은 XZ 평면 기준이라 Y값은 무시해요.

### flatten 옵션

| 옵션 | 기본값 | 의미 |
|---|---|---|
| `height=<y\|auto>` | `auto` | 기준 높이예요. `auto`면 영역의 중앙값을 써서 깎는 양과 채우는 양이 비슷해져요 |
| `rough=<n\|auto>` | `auto` | 기복의 최대 높이(블록)예요. `auto`면 주변 지형의 거칠기에 맞춰 0.4~2 사이로 정해요. `0`이면 완전한 평면이에요 |
| `scale=<n>` | `48` | 기복의 가로 크기예요. 클수록 더 완만한 언덕이 돼요 |
| `feather=<n>` | `/mt edge` 값 | 이번 실행에만 쓸 가장자리 스무딩 폭이에요. 이 폭만큼 바깥 지형과 부드럽게 이어 줘요. `0`이면 경계가 각지게 끊겨요 |
| `smooth=<n>` | `2` | 마무리 스무딩을 몇 번 할지예요 |
| `trees=<clear\|keep>` | `clear` | 영역 안의 나무와 풀을 치울지 정해요. `keep`이어도 높이가 바뀌는 칸은 위쪽을 비워요 |
| `seed=<n>` | 월드 시드 | 노이즈 시드예요. 같은 시드면 이웃한 영역끼리도 기복이 이어져요 |

예시:

```
/mt flatten                         # 주변에 맞춘 자연스러운 평지
/mt flatten height=70 rough=0       # Y=70 완전 평면
/mt flatten rough=2 scale=80        # 넓고 완만한 언덕이 있는 평원
```

## 알고리즘

### 바닐라 지형 분석

1.18 이후의 바닐라 지형은 3D 밀도 함수로 만들어져요. 지형의 큰 모양을 정하는 노이즈는 네 가지예요.

- **continentalness**: 바다와 내륙을 나눠요
- **erosion**: 침식 정도예요. 값이 높을수록 지형이 낮고 평평해져요
- **peaks & valleys (weirdness)**: 봉우리와 골짜기를 만들어요
- **jaggedness**: 산의 뾰족함을 더해요

이 값들이 스플라인을 거쳐 지형 높이 offset과 factor가 돼요. **평원은 erosion이 높은 경우**예요. offset이 거의 변하지 않아서, 결국 진폭이 작은 옥타브 Perlin 노이즈만 남아요. 그리고 erosion 자체도 천천히 변하기 때문에 같은 평원 안에서도 더 평평한 곳과 조금 울퉁불퉁한 곳이 섞여 있어요.

### Motopoly가 하는 일 (`FlattenPlanner`)

1. **표면 읽기**: 청크 스냅샷에서 칸마다 맨 위 지형 블록을 찾아요. 이때 나무, 잎, 풀, 물, 버섯 블록 등은 지형이 아니라서 건너뛰어요.
2. **기준 높이**: 영역 높이의 중앙값을 써요. 깎는 양과 채우는 양이 비슷해져요.
3. **기복**: 바닐라 `ImprovedNoise`와 같은 구조(셔플된 순열 + 16방향 그래디언트)로 4옥타브 Perlin 노이즈를 만들어요. 여기에 더 느린 "erosion" 노이즈를 곱해서 진폭이 지역마다 35~100% 사이에서 달라지게 해요.
4. **테두리 블렌딩**: 테두리에서 안쪽으로 `feather`칸까지 smoothstep 가중치로 원래 높이와 섞어서 절벽이 생기지 않게 해요.
5. **스무딩**: 1-2-1 커널로 블러한 뒤 정수 높이로 반올림해요.
6. **블록 재구성** (`FlattenJob`): 칸마다 원래의 재질 층(예: 잔디 → 흙 3칸 → 돌)을 복사해서 새 높이에 그대로 다시 쌓아요. 그래서 사막은 모래/사암으로, 눈 덮인 지역은 원래 표면 블록으로 채워져요.

`/mt info`의 거칠기는 4-이웃 라플라시안의 절댓값 평균이에요. 바닐라 평원은 대략 0.2~0.8, 구릉은 1~2, 산악은 2를 넘어요.

### 성능

- 청크는 비동기로 로드하고, 높이 분석과 변경 목록 계산은 비동기 스레드에서 해요.
- 블록 쓰기는 메인 스레드에서 틱당 `blocks-per-tick`개씩 나눠서, 물리 연산 없이 해요.
- 되돌리기 기록은 블록 위치를 long 하나에 압축하고 블록 상태는 팔레트로 저장해요. 수백만 블록을 바꿔도 메모리를 적게 써요.

## 알아둘 점

- 가장자리 스무딩은 **선택 영역 안쪽**에서 일어나요. 폭이 10이면 테두리 10블록은 주변 지형으로 이어지는 경사가 되고, 그 안쪽만 완전히 평평해져요. 건물 부지보다 사방으로 그 폭만큼 넓게 선택하세요.

- 영역 안의 물은 새 지표면 위에 있으면 지워져요. 물리 연산을 끄고 써서 바로 흐르지는 않지만, 영역 경계에 호수가 걸쳐 있으면 물 벽이 남을 수 있어요.
- 영역 밖까지 뻗은 나뭇잎은 그대로 남아요.
- 작업 중에 다른 사람이 그 영역을 고치면, 그 변경은 덮어써질 수 있어요.
