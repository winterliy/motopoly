# Motopoly

WorldEdit처럼 구역을 고르고 높이를 정하면, 그 자리를 **그 높이의 땅으로 올리거나 내리면서 주변 지형과 자연스럽게 이어 주는** Paper 플러그인이에요. 건축 부지를 만들 때 써요.

- 구역 안에 원래 있던 것(건물, 나무, 물, 구덩이)은 무시하고, **목표 높이와 바깥 테두리 지형**만 보고 새 지표면을 설계해요.
- 새 지표면 위의 블록은 전부 지우고, 아래 빈 공간(공기, 물)은 땅으로 채워요.
- 대상: Paper 26.3 (Java 25)
- 언어: 지형 알고리즘은 Java(`src/main/java`), 플러그인 연결부는 Kotlin(`src/main/kotlin`)

## 설치

```bash
./gradlew build
```

`build/libs/motopoly-<버전>.jar`를 서버의 `plugins/` 폴더에 넣으면 돼요. Kotlin 런타임은 jar에 넣지 않았어요. 서버가 처음 켜질 때 `plugin.yml`의 `libraries` 항목을 보고 Maven Central에서 내려받아요.

## 사용법

1. **구역 지정**: `/mt pos1`, `/mt pos2`로 지금 서 있는 위치를 두 꼭짓점으로 찍어요. `/mt wand`로 받은 황금 삽으로 좌클릭/우클릭해도 돼요.
2. **땅 생성**: `/mt gen <y>`를 치면 구역의 땅을 Y 높이로 올리거나 내려요. 테두리는 주변 지형과 자연스럽게 이어지고, 지표면 블록은 주변을 분석해서 같은 재질로 깔아요.
3. **설정 변경**: `/mt config <smooth|rough> [값]`으로 바꿔요. 값을 빼면 기본값으로 돌아가요.
4. **되돌리기**: `/mt undo`로 마지막 작업을 되돌려요 (기본 5단계).

| 명령어 | 설명 |
|---|---|
| `/mt pos1`, `/mt pos2` | 구역 꼭짓점 지정 |
| `/mt wand` | 선택 도구(황금 삽) 받기. 좌클릭 1번, 우클릭 2번 지점 |
| `/mt gen <y>` | 구역 땅을 Y 높이로 생성 (`/mt generate`도 돼요) |
| `/mt config` | 현재 설정 보기 |
| `/mt config smooth [0~64]` | 가장자리 스무딩 폭(블록). 기본 10 |
| `/mt config rough [auto\|0~16]` | 기복 높이(블록). 기본 auto, 0이면 완전 평면 |
| `/mt undo` | 마지막 작업 되돌리기 |
| `/mt info` | 구역과 주변 지형 분석, 추천 높이 |
| `/mt help` | 사용 순서 보기 |
| `/mt reload` | `config.yml` 다시 불러오기 |

- 권한은 `motopoly.use`(기본값: OP)예요.
- `smooth`와 `rough`는 플레이어마다 저장돼서 서버를 재시작해도 유지돼요. 서버 기본값은 `config.yml`의 `defaults`에서 바꿔요.
- 선택 도구는 황금 삽이라 WorldEdit의 나무 도끼와 겹치지 않아요.

예시:

```
/mt pos1
/mt pos2
/mt gen 70                 # 구역을 Y=70으로, 테두리 10블록은 주변과 이어지는 경사
/mt config smooth 16       # 경사를 더 길고 완만하게
/mt config rough 0         # 기복 없는 완전 평면
/mt config rough           # 기본값(auto)으로 되돌리기
```

## 알고리즘

### 바닐라 지형 분석

1.18 이후의 바닐라 지형은 3D 밀도 함수로 만들어져요. 지형의 큰 모양을 정하는 노이즈는 네 가지예요.

- **continentalness**: 바다와 내륙을 나눠요
- **erosion**: 침식 정도예요. 값이 높을수록 지형이 낮고 평평해져요
- **peaks & valleys (weirdness)**: 봉우리와 골짜기를 만들어요
- **jaggedness**: 산의 뾰족함을 더해요

**평원은 erosion이 높은 경우**예요. 큰 높낮이가 거의 사라지고, 진폭이 작은 옥타브 Perlin 노이즈만 남아요.

### Motopoly가 하는 일 (`TerrainGenerator`)

1. **주변 읽기**: 구역과 사방 8블록 여백의 청크 스냅샷에서 칸마다 지표면을 찾아요. 나무, 잎, 풀은 건너뛰고, 물은 수면 높이로 봐요. 그래서 호숫가에서는 새 땅이 물가처럼 수면에 맞닿아요.
2. **막 곡면 (라플라스 보간)**: 구역 바로 바깥 한 줄의 높이를 고정하고, 안쪽은 라플라스 방정식을 풀어 채워요. 이렇게 만든 곡면은 모든 테두리에 딱 맞는 가장 매끄러운 곡면이에요. 한쪽이 높고 반대쪽이 낮으면 그 사이를 자연스러운 경사로 이어요. 계산은 SOR(과완화 반복법)로 해요.
3. **목표 높이** (`/mt gen <y>`): 테두리에서 `smooth`칸에 걸쳐 S자 곡선(smoothstep)으로 막 곡면에서 Y 높이까지 서서히 바꿔요. 그 안쪽은 Y 높이예요.
4. **자연스러운 기복 (바닐라 지형)**: 같은 시드·같은 생성기로 만든 숨은 참조 월드(`motopoly_ref_<월드이름>`)에서, 그 좌표를 바닐라가 생성한 높이를 읽어요. 이 높이에서 흐리게 만든 복사본을 빼서(하이패스 필터) 산·골짜기 같은 큰 모양은 버리고, `scale/4`블록보다 작은 **진짜 바닐라의 잔 굴곡**만 남겨요. 이 굴곡의 크기를 `rough`에 맞춘 뒤 `smooth`칸에 걸쳐 서서히 더해서, 경계에서는 높이가 주변과 딱 맞아요.
   - 참조 월드를 못 쓰거나(`reference-terrain: false`) 그 자리가 완전히 평평하면, 바닐라 평원을 흉내 낸 4옥타브 Perlin 노이즈로 대신해요. 이때는 느린 "erosion" 노이즈로 기복 세기를 지역마다 35~100% 사이로 바꿔요.
5. **스무딩**: 1-2-1 커널로 블러한 뒤 정수 높이로 반올림해요.
6. **블록 배치** (`GenerateJob`):
   - 새 지표면 위는 꼭대기까지 전부 공기로 바꿔요. 건물, 나무, 횃불, 물이 모두 지워져요.
   - 지표면에는 **참조 월드의 같은 좌표에 있는 바닐라 재질 층**을 깔아요. 예를 들어 잔디 → 흙 3칸 → 돌이에요. 그 자리가 원래 물 밑이었으면 가장 가까운 바깥 테두리 칸의 재질을 써요.
   - 그 자리에 원래 났을 **풀·꽃·고사리·큰 풀·눈 덮개**도 참조 월드에서 그대로 옮겨 심어요(`copy-plants`). 나무는 옮기지 않아요.
   - 그 아래 공기나 물은 단단한 땅이 나올 때까지 채워요. 최대 `max-fill-depth`(기본 64)블록이에요.

`/mt info`의 거칠기는 4-이웃 라플라시안의 절댓값 평균이에요. 바닐라 평원은 대략 0.2~0.8, 구릉은 1~2, 산악은 2를 넘어요.

### 성능

- 청크는 비동기로 로드하고, 지형 분석과 변경 목록 계산은 비동기 스레드에서 해요.
- 블록 쓰기는 메인 스레드에서 틱당 `blocks-per-tick`개씩 나눠서, 물리 연산 없이 해요.
- 되돌리기 기록은 블록 위치를 long 하나에 압축하고 블록 상태는 팔레트로 저장해요. 수백만 블록을 바꿔도 메모리를 적게 써요.

## 알아둘 점

- 처음 `/mt gen`을 칠 때 참조 월드를 만드느라 서버가 몇 초(테스트에서 약 3초) 멈칫해요. 서버를 켤 때마다 한 번씩만 그래요. 참조 월드 폴더(`motopoly_ref_world` 등)는 서버 폴더에 남는데, 지워도 다음에 다시 만들어져요.

- 구역 안의 건물도 지표면 위에 있으면 모두 지워져요. 실수했다면 `/mt undo`로 되돌리세요.
- 구역 바로 바깥에 건물이 붙어 있으면, 그 건물 높이를 지형으로 보고 이어질 수 있어요. 구역을 건물에서 조금 떨어뜨려 잡으세요.
- 물리 연산을 끄고 써서, 구역 경계에 걸친 물은 바로 흘러들지 않고 물 벽처럼 남을 수 있어요.
- 작업 중에 다른 사람이 그 구역을 고치면, 그 변경은 덮어써질 수 있어요.

## 테스트

```bash
./gradlew test
```

`TerrainGeneratorTest`는 다음을 확인해요: 평평한 주변이면 평평한 땅, 구역 안 원래 지형 무시, 경사를 매끄럽게 연결, 목표 높이 도달과 경계 연속성, 기복 범위, 시드 재현성, 주변 통계, 거칠기 자동 계산, 바닐라 굴곡 추출(경사 제거·잔 굴곡 보존), 참조 지형 적용과 노이즈 대체.
